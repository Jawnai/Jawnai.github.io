# 📘 สมุดบันทึกของฉัน (Personal Diary & Work/Expense Tracker PWA)

เว็บแอปพลิเคชัน **"สมุดบันทึกส่วนตัว"** ออกแบบมาสำหรับใช้งานคนเดียว เน้นการใช้งานบนมือถือเป็นหลัก (Mobile-First) แสดงผลเป็นภาษาไทย 100% พร้อมติดตั้งเป็น **Progressive Web App (PWA)** ลงบนหน้าจอโฮมของมือถือได้ทั้ง iOS และ Android ใช้งานได้แบบเต็มจอ และบันทึกข้อมูลได้แม้ไม่มีอินเทอร์เน็ต (Offline-first)

---

## ✨ ฟีเจอร์หลัก

### 1. หมวดหมู่การบันทึก (6 หมวดหลัก)
1. **💼 การทำงาน (Work Logs)**:
   - บันทึกสถานที่ทำงาน (พิมพ์ใหม่ หรือเลือกจากสถานที่ที่เคยบันทึกไว้)
   - เลือกวันที่จากปฏิทิน (ค่าเริ่มต้นคือวันนี้)
   - บันทึกเวลาเข้างาน และเวลาออกงาน
   - **คำนวณชั่วโมงทำงานให้อัตโนมัติทันที** รองรับการทำงานข้ามคืน
   - บันทึกหมายเหตุเพิ่มเติมได้
2. **🚗 ค่าใช้จ่ายระหว่างไปทำงาน (Work Expenses)**:
   - ประเภท: ค่าน้ำมัน, ค่าเดินทาง (รถไฟฟ้า/แท็กซี่/รถเมล์), ค่าทางด่วน, ค่าจอดรถ, อื่น ๆ
   - ระบุจำนวนเงิน (บาท ฿)
   - เลือกผูกกับรายการ "การทำงาน" ของวันนั้นได้
3. **🧾 บิลที่ต้องรับเงิน (Receivables / Bills)**:
   - บันทึกรายการเบิกบริษัท หรือเงินที่ต้องเก็บจากลูกค้า / เพื่อน
   - ระบุจำนวนเงิน, วันที่ออกบิล, วันที่ครบกำหนด
   - สลับสถานะได้ในคลิกเดียว: **"ยังไม่ได้รับ" ↔ "ได้รับแล้ว"** (พร้อมเอฟเฟกต์พลุ Confetti เมื่อรับเงิน)
   - **แนบรูปถ่ายใบเสร็จ** (ระบบบีบอัดภาพให้อัตโนมัติ พร้อมปุ่มเปิดดูรูปขนาดเต็ม)
   - การ์ดสรุปยอดรวมที่ยังค้างรับเงิน
4. **🍛 ค่าข้าว / อาหาร (Food Expenses)**:
   - เลือกมื้อ: มื้อเช้า / มื้อกลางวัน / มื้อเย็น / ของว่างและอื่น ๆ
   - ระบุจำนวนเงิน วันที่ และหมายเหตุ
5. **☕ ค่ากาแฟ / เครื่องดื่ม (Coffee Expenses)**:
   - ปุ่มลัดเลือกเมนูยอดนิยม (เช่น อเมริกาโน่, ลาเต้, ชาไทย, Amazon, Starbucks) หรือพิมพ์เอง
   - ระบุจำนวนเงิน วันที่ และหมายเหตุ
6. **🏷️ ค่าใช้จ่ายนอกเหนือรายการ (Custom Expenses)**:
   - พิมพ์ชื่อรายการ
   - **สร้างหมวดหมู่ใหม่เองได้ทันที** (เช่น ค่าเน็ตบ้าน, สุขภาพ, ช้อปปิ้ง) และระบบจะจำไว้ให้เลือกใช้ในครั้งถัดไป
   - ระบุจำนวนเงิน วันที่ และหมายเหตุ

---

### 2. หน้าแรก (Dashboard)
- **สรุปวันนี้**: ทำงานที่ไหน กี่ชั่วโมง และใช้เงินไปเท่าไรในวันนี้
- **การ์ดยอดบิลค้างรับ**: แจ้งเตือนยอดเงินที่ยังรอเก็บ พร้อมจำนวนบิล และปุ่มลัด
- **สัดส่วนค่าใช้จ่าย (Donut Chart)**: กราฟวงกลมแสดง % และยอดเงินแยกตามหมวดหมู่
- **ปุ่มกรองช่วงเวลา**: สรุปยอด วันนี้ / สัปดาห์นี้ / เดือนนี้ / ทั้งหมด
- **รายการบันทึกล่าสุด**: 5 รายการล่าสุด แตะเพื่อดูรายละเอียด
- **ปุ่ม "+" ลอย (FAB)**: อยู่ตรงกลางแถบล่าง แตะเพื่อเลือกหมวดหมู่ที่ต้องการบันทึกได้อย่างรวดเร็ว

---

### 3. ประวัติย้อนหลังและปฏิทิน (History & Calendar)
- สลับมุมมองได้ 2 แบบ:
  - 📋 **มุมมองรายการ (List View)**: แสดงทุกรายการเรียงตามวันที่ พร้อมป้ายหมวดหมู่และสีประจำหมวด
  - 📅 **มุมมองปฏิทิน (Month Calendar)**: ปฏิทินแสดงจุดสีบอกวันที่ทำงานและวันที่เกิดค่าใช้จ่าย แตะวันที่ในปฏิทินเพื่อกรองดูเฉพาะวันนั้นได้ทันที
- ช่องค้นหาข้อความ (ค้นหาจากสถานที่, ชื่อรายการ, หมายเหตุ)
- ปุ่มชิปกองตามหมวดหมู่ (การทำงาน, ค่าเดินทาง, รอรับเงิน, ค่าข้าว, ค่ากาแฟ, ทั่วไป)
- ปุ่ม **แก้ไข (Edit)** และ **ลบ (Delete)** ทุกรายการ พร้อมหน้าต่างยืนยันความปลอดภัย

---

### 4. ระบบ PWA และการเก็บข้อมูลในเครื่อง
- **ติดตั้งลงหน้าจอมือถือได้ (PWA)**:
  - มีไฟล์ `manifest.json`, Web Manifest, Theme Color, Standalone Mode (ไม่มีแถบ URL เบราว์เซอร์)
  - ไอคอนแอปครบทุกขนาด (192x192, 512x512, Maskable Icon และ Apple Touch Icon สำหรับ iPhone)
  - Service Worker แคชไฟล์ทั้งหมด ใช้งานได้แบบ **Offline 100%**
  - มีปุ่ม "ติดตั้งแอปลงหน้าจอ" สำหรับ Android ในหน้าตั้งค่า
  - มีการ์ดแนะนำวิธีติดตั้งทีละขั้นตอนสำหรับ iPhone (Safari)
  - แจ้งเตือนเมื่อมีเวอร์ชันใหม่ ("มีอัปเดตใหม่ กดเพื่อโหลดใหม่")
- **IndexedDB (Dexie.js)**: ข้อมูลทั้งหมดถูกเก็บไว้ในเครื่องผู้ใช้ ไม่รั่วไหล ข้อมูลไม่หายเมื่อปิดแอปหรืออัปเดตเวอร์ชัน
- **สำรองและกู้คืน (Backup & Restore)**: ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ `.json` และสามารถนำเข้ากู้คืนข้อมูลได้ตลอดเวลา
- **ส่งออก Excel / CSV**: ส่งออกข้อมูลทั้งหมดเป็นไฟล์ `.csv` เข้ารหัสแบบ UTF-8 BOM ทำให้เปิดในโปรแกรม Microsoft Excel บน Windows และ Mac ได้ทันทีโดยสระภาษาไทยไม่เพี้ยน
- **โหมดมืด / สว่าง (Dark / Light Mode)**: รองรับโหมดมืด ถนอมสายตา และมีตัวเลือกตามการตั้งค่าของระบบ

## 🚀 วิธีติดตั้งและรันในเครื่อง (Local Development)

### ข้อกำหนดเบื้องต้น
- ติดตั้ง [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป แนะนำ v20 หรือ v22)

### ขั้นตอนการรัน
1. เปิด Terminal ในโฟลเดอร์โปรเจกต์:
   ```bash
   cd /Users/thitiwut.k/Desktop/Jawnai.github.io/jawnai
   ```

2. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```

3. รัน Development Server:
   ```bash
   npm run dev
   ```

4. **ทดสอบเปิดบนมือถือผ่าน Wi-Fi เดียวกัน**:
   ```bash
   npm run dev -- --host
   ```
   Terminal จะแสดง Network URL เช่น `http://192.168.1.XX:5173` ให้นำ URL นี้ไปเปิดในเบราว์เซอร์ของมือถือ

5. บิลด์สำหรับใช้งานจริง:
   ```bash
   npm run build
   ```

## 🌐 วิธีนำขึ้นเว็บฟรี (Deploy to Production)

เพื่อให้สามารถเปิดจากมือถือผ่าน HTTPS และกด **"ติดตั้งลงหน้าจอมือถือ"** ได้ แนะนำให้นำขึ้นบริการโฮสติ้งฟรีต่อไปนี้:

### ทางเลือกที่ 1: Vercel (แนะนำ ง่ายและเร็วที่สุด)
1. สมัครใช้งานฟรีที่ [Vercel.com](https://vercel.com/)
2. ติดตั้ง Vercel CLI (หรือเชื่อมต่อกับ GitHub):
   ```bash
   npx vercel
   ```
3. กด `Enter` ตามขั้นตอน Vercel จะตรวจพบว่าเป็นโปรเจกต์ Vite โดยอัตโนมัติ และให้ URL เว็บไซต์จริง (มี HTTPS ให้ฟรี)
4. เปิด URL นั้นบนมือถือ แล้วกดติดตั้งลงหน้าจอได้ทันที

### ทางเลือกที่ 2: Netlify (ฟรีและง่ายมาก)
1. บิลด์โปรเจกต์ในเครื่อง:
   ```bash
   npm run build
   ```
2. สมัครใช้งานฟรีที่ [Netlify.com](https://www.netlify.com/)
3. ไปที่เมนู **Sites** แล้วลากโฟลเดอร์ `dist` ไปวางในหน้าเว็บ Netlify (Drag & Drop)
4. Netlify จะสร้าง URL เว็บไซต์พร้อม HTTPS ให้ทันที

### ทางเลือกที่ 3: GitHub Pages
เนื่องจากโฟลเดอร์นี้อยู่ใน Git repository ของ GitHub (`Jawnai.github.io`):
1. Push โค้ดขึ้น GitHub repository
2. ไปที่ **Settings** > **Pages** ของ Repository ใน GitHub
3. เลือก Source เป็น **GitHub Actions** และเลือกเทมเพลต **Static HTML / Vite**
4. ทุกครั้งที่ push โค้ด GitHub จะทำการ build และ deploy เว็บให้อัตโนมัติ

## 📱 วิธีติดตั้งลงหน้าจอโฮมของมือถือ

### สำหรับ Android (Google Chrome):
1. เปิดลิงก์เว็บไซต์ผ่าน Google Chrome
2. จะมีแถบขึ้นมาถาม "เพิ่มไปยังหน้าจอหลัก" หรือเข้าไปที่หน้า **"ตั้งค่า"** ในแอป แล้วแตะปุ่ม **"ติดตั้งแอปลงหน้าจอมือถือ"**
3. ไอคอนแอปจะไปปรากฏบนหน้าจอหลัก เมื่อเปิดจะทำงานแบบเต็มจอไม่มีแถบเบราว์เซอร์

### สำหรับ iPhone / iPad (Safari):
1. เปิดลิงก์เว็บไซต์ด้วย **Safari** (จำเป็นต้องใช้ Safari สำหรับ iOS)
2. แตะปุ่ม **แชร์ (Share)** รูปสี่เหลี่ยมมีลูกศรชี้ขึ้น ที่แถบด้านล่าง
3. เลื่อนลงแล้วแตะ **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
4. แตะ **"เพิ่ม" (Add)** ที่มุมขวาบน
5. แอปจะเปิดใช้งานแบบเต็มจอ สวยงาม เสมือนแอปแท้จาก App Store
